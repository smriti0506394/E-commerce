# E-Commerce Sales Analysis & Machine Learning

##  Project Overview
This project explores e-commerce sales data using Python, applies machine learning algorithms, and presents business insights through an interactive Power BI dashboard.

The goal is to understand sales trends, customer behavior, product performance, and explore machine learning approaches for e-commerce data.

##  Technologies Used
- **Python**  Data processing and analysis
- **Pandas & NumPy**  Data cleaning and manipulation
- **Matplotlib**  Data visualization
- **Scikit-learn**  Machine learning
- **Jupyter Notebook**  Analysis and model experimentation
- **Power BI**  Interactive dashboard development

##  Project Files

| File | Description |
|---|---|
| `E_commerse.ipynb` | Data cleaning, exploratory data analysis, and visualizations |
| `ML_E_commerse.ipynb` | Machine learning experiments and model evaluation |
| `E-commerce.csv` | Original dataset |
| `cleaned_ecommerce_data.csv` | Processed dataset used for analysis and modeling |
| `E-commerce_dashboard.pbix` | Power BI dashboard |
| `random_forest_model.pkl` | Saved Random Forest model |

##  Data Analysis
The exploratory data analysis includes:
- Data cleaning and missing-value handling
- Conversion of price and discount columns into numeric formats
- Revenue analysis by product category
- Payment method distribution
- Customer age and rating analysis
- Order counts by city
- Unit price and revenue comparisons

##  Machine Learning
Multiple machine learning algorithms were explored:
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)

The models were experimented with and evaluated to explore their performance on the available dataset.

**Note:** Model performance should be interpreted using suitable evaluation metrics, not accuracy alone.

##  Power BI Dashboard
The Power BI dashboard provides a visual way to explore e-commerce data and understand key business patterns.

Open `E-commerce_dashboard.pbix` using Microsoft Power BI Desktop.

## How to Run the Project

1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib scikit-learn jupyter
   ```

4. Keep the CSV files in the locations expected by the notebooks.
5. Open the notebooks in Jupyter and run the cells.
6. Open the `.pbix` file in Power BI Desktop to explore the dashboard.
